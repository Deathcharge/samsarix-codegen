# Support

- Product help and bug reports: open a GitHub issue after removing secrets and private source code.
- Account, business, and licensing questions: `contact@samsarix.com`.
- Private support and vulnerability reports: `support@samsarix.com`.

Samsarix Codegen is currently a `0.2.0` release candidate. Support is best-effort; no service-level
agreement or guaranteed response time is included with the open-source package.
